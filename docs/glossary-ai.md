# AI glossary

Written for: the project owner, Marketing and developers, so that AI feature labels in the portal use the same terms.
Definitions are paraphrased from Wikipedia. Wikipedia text is licensed CC BY-SA 4.0. Source links are given for each term.

## Generative AI (GenAI)

A subfield of artificial intelligence that uses generative models to produce new content, such as text, images, video, audio, computer code or other digital data. The models learn patterns and structures from their training data, then generate new data in response to an input, usually a natural-language prompt.

Source: [Generative artificial intelligence, Wikipedia](https://en.wikipedia.org/wiki/Generative_artificial_intelligence)

**Portal use:** the summaries and auto-metadata features (brief F10, §8). Their output is labelled **AI-suggested** until a person confirms it.

## Agentic AI

Systems built around an AI agent: a program that makes decisions, pursues goals and takes actions. Unlike narrower tools, such as a chatbot that only answers questions, or a traditional machine-learning model that only predicts a result, an agentic system plans multi-step work and acts on it.

Source: [Agentic AI, Wikipedia](https://en.wikipedia.org/wiki/Agentic_AI)

**Portal use:** none in v1. The request triage (brief §8.7) takes actions only as suggestions, with a person deciding. Any future agentic behaviour needs its own ADR.

## Retrieval-augmented generation (RAG)

Not defined here yet. It is the pattern used by Ask-AI search (brief §8.2): retrieve permitted collateral first, then generate an answer that cites it. Add a definition in Phase 6.
